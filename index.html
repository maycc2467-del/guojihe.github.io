01 / Project Background

业务溯源：数字赋能乡村文旅

🌱

资源丰富但触达受限

郭家河乡拥有得天独厚的自然生态湿地与深厚的红廉文化底蕴，但由于缺乏统一的数字化阵地，优质资源难以精准触达潜在客群，信息呈现碎片化。

🗺️

游览体验缺乏沉浸感

传统的线下导览模式单一，游客在实地游览时缺乏深度的文化解说与互动，导致“走马观花”，难以形成深刻的情感连接与文化认同。

🔄

游后转化与传播断层

游客离场后缺乏有效的留存机制，特色农产品与文创商品难以实现长尾转化，游客自发分享分享的门槛较高，口碑裂变效应不足。

设计破局点 (Design Goal)

打造一个集“游前种草规划+游中沉浸导览+游后回味转化”为一体的智慧文旅平台，以数字化手段激活乡村文旅产业，提升游客全链路体验，最终实现文化传播与经济收益的双赢。

02 / User Insights

调研解码：听见真实的声音

基于对135位有效用户的问卷数据深度剖析，我们精准描绘了郭家河文旅的核心客群画像，洞悉了他们在各个阶段的深层需求。

性别与客源地分布

年龄与职业构成

典型用户画像：轻中产及职场人群

数据显示，核心客群集中在19-40岁（占比超80%），职业以企业职员（42%）与企事业单位人员（28%）为主。女性受众（61%）显著高于男性。
结论：这部分人群具有一定的消费能力，渴望在周末或短假远离都市喧嚣，追求有品质的自然放松与深度的文化体验。

出行特征：微度假与省内游

客源地以河南省内（占比超50%）为主，停留时间大多选择1-3晚（56%）或当天往返（37%）。
结论：“周边微度假”是核心场景。平台需要提供高效的“一站式”短途游攻略与预订服务，降低出行决策成本。

信息获取渠道偏好

核心关注体验要素 (多选)

03 / Journey Map & Design Goals

体验链路推导：五步重塑文旅旅程

突破传统文旅工具的局限，我们将用户旅程细化为5个核心阶段。基于数据洞察，将用户的“痛点/需求”通过链条式推导，转化为产品功能的“设计目标”，打造无缝衔接的沉浸式服务。

01

规划准备 Pre-trip Planning

“不知道该怎么玩，信息太分散”

数据支撑

▪ 72.6% 用户需要图文视频景点介绍

▪ 54.1% 需要预订机票、酒店、门票

🎯 设计目标：种草激发与降阻预订

打破传统政务式展示，打造“内容前置”的种草广场。利用丰富的视觉素材吸引用户，同时提供从路线推荐到住宿门票的一站式预订入口，大幅降低出行决策的时间成本。

02

前往目的地 On the Way

“路上心里没底，希望一切顺利”

数据支撑

▪ 51.1% 强需求实用信息查询(天气、交通)

▪ 38.5% 关注实时交通与停车信息

🎯 设计目标：预期管理与安心护航

在用户出发前及路途中，平台充当“贴身助理”。首页置顶动态天气提示与交通微件，缓解对未知路况的焦虑，建立安全感，提升用户对郭家河文旅服务的初印象。

03

到达与初步体验 Arrival & First Impression

“刚到这，车停哪？洗手间在哪？”

数据支撑

▪ 60.0% 需要清晰的卫生间、饮水点标识

▪ 48.1% 需要基于位置的地图导航定位

🎯 设计目标：刚需前置与履约保障

解决“第一公里”的痛点。设计服务大厅刚需金刚区，将卫生间、停车场、医疗点等设施查找高亮显示。结合LBS地图，实现一键导航，保障基础服务体验的流畅无缝。

04

深入游玩体验 In-depth Experience

“这棵古树有故事吗？想深度参与。”

数据支撑

▪ 68.1% 希望到达景点时有语音/图文解说

▪ 50.3% 喜欢打卡集章等游戏化探索系统

🎯 设计目标：文化解码与探索激励

化“走马观花”为“沉浸探索”。设计伴随式智能导览，走到哪讲到哪，深挖红色文化与自然知识。同时引入“数字徽章收集”系统，以游戏化的激励机制引导游客走遍全乡，延长游览时间。

05

返程与回顾 Post-trip Reflection

“好想把特产带回去，把回忆分享出去”

数据支撑

▪ 61.5% 期待平台提供“一键游记生成助手”

▪ 31.1% 希望购买特色商品或获得复购优惠

🎯 设计目标：裂变留存与长尾转化

构建游后的商业与口碑闭环。提供低门槛的Vlog/游记模板促进社交裂变；打造“特产商城”模块，通过游玩积分兑换优惠券的方式，将线下体验流量转化为线上农产品复购流量。

05 / UI Solutions

界面演绎：将需求转化为可视的体验

01

首页探索：所见即向往

化繁为简的信息分发枢纽

响应问卷中"72.6%用户需要图文视频介绍"的诉求，首页弱化了工具属性，强化了“内容种草”：

  • ✓ 情境头图： 采用大幅湿地风景，配合“心栖梦归处”文案，建立初印象。
  • ✓ 金刚区重组： 将问卷中高频需求的“酒店民宿”、“服务资讯”、“路线定制”前置，提升找寻效率。
  • ✓ 内容瀑布流： “精选推荐”融合了活动预告、短视频与游记，满足用户多维度的攻略浏览需求。
02

智能导览：伴随式的云端导游

满足游中核心痛点：68.2%需要景点解说

导览模块不仅是地图，更是连接用户与当地文化历史的桥梁：

  • ✓ 半屏交互架构： 地图层与信息层上下分离。上半屏保留沉浸式视觉，下半屏展示基于定位的结构化数据（如：3A级景区标签、详情介绍、近期活动）。
  • ✓ LBS推荐： “附近景点”模块根据实时距离智能排序，解决游客实地“迷茫感”。
  • ✓ 温馨提示栏： 融入人性化关怀（如：早晚温差大，请注意保暖），提升整体好感度。
03

服务聚合与转化设计

一站式解决：从刚需到增值服务

为响应问卷中"60%用户需要查找卫生间标识"以及"一站式预订"的需求，服务页采用清晰的分类逻辑：

  • ✓ 服务大厅归类： 将零散的功能划分为“游前必备”、“出行助手”、“游后反馈”三大生命周期板块，符合用户认知模型。
  • ✓ 跟团游与活动预定： “绿色生态游”、“红色主题游”等定制线路（对应问卷中高关注度的两大板块）以大图卡片呈现，标明价格促转化。
  • ✓ 活动日历时间轴： 农产品展销会、丰收节等活动以时间轴插画形式展现，增强活动的代入感与趣味性。
04

特产商城：延续文化长尾

线上选购，新鲜到家

文旅平台的终局不仅是体验，更要赋能乡村振兴：

  • ✓ 品类聚焦： 提炼“农产品”、“文创产品”、“手工制品”三大核心品类，主打地方特色（如：大别山间茶、手工竹编背篓）。
  • ✓ 视觉营销： 顶部通栏场景大图提升产品的高级感与源头信任感，“郭家河畔水，大别山间茶”文案传递文化温度。
